# Гонка, которую ты докажешь

Сделайте свою копию репозитория. Откройте корневой проект в IntelliJ IDEA и выберите JDK 25 для Gradle. [Условие и критерии сдачи](ASSIGNMENT.md).

| Команда в PowerShell | Что запускается |
| --- | --- |
| `.\gradlew.bat build` | Сборка, последовательный пример для обеих версий индексатора и проверка запуска Lincheck. |
| `.\gradlew.bat :proof:raceProof -Pkfd.target=given` | Ваш конкурентный тест для исходной версии. |
| `.\gradlew.bat :proof:raceProof -Pkfd.target=fixed` | Тот же тест для исправленной версии. |

В Linux и macOS используйте `./gradlew` вместо `.\gradlew.bat`. Для первой сборки нужен доступ к репозиториям зависимостей. Обе версии индексатора в шаблоне одинаковы. Первоначальная сборка должна пройти. Специализированная проверка `raceProof` содержит заготовку для вашего сценария и при первом запуске остановится на ней.

## Отчёт

1. **Дефект.** Дайте ссылки на стартовый коммит и строки исходника. Запишите ожидаемую статистику для вашего примера и покажите в трассе, где результат расходится с ожиданием.
2. **Исправление.** Дайте ссылку на изменённые строки и объясните гарантию, которую они обеспечивают.
3. **Проверки.** Приложите первую трассу, две строки `RACE-PROOF` и ссылки на успешные запуски `ci` и `race-proof`.
4. **Замеры.** Укажите JDK, ОС, процессор, число доступных ядер, единицы измерения, прогрев, отдельные результаты, медианы и разброс для трёх конфигураций. Сформулируйте вывод о цене исправления и масштабировании. [Запись о выборе решения](docs/adr-001-concurrency.md).
